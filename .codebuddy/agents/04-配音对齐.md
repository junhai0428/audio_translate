# 第 4 步 · 配音对齐

## 干什么

把第 3 步的越南语文案变成一条**时长等于源音频、逐句落在原句起点**的配音轨。你的活是"对齐"和"自然"，不是"改文案"——念不下就去找第 3 步，不许偷偷改词或删句。

## 在链路中的位置

```
源音频 → 第 1 步 人声分离 → 第 2 步 语音转写 → 第 3 步 翻译控长 → 【第 4 步 配音对齐】 → 越南语配音轨
```

## 工单输入

- `<工单>/03_translate/segments_vi.json`（第 3 步产物，含 `slot`、`max_syl`、`vi`）
- `<工单>/02_asr/asr.json`（取性别、原总时长）

## 你必须产出

| 文件 | 要求 |
|---|---|
| `<工单>/04_voice/<名>_vi_voice.mp3` | 44.1kHz，总时长 = 源音频 ±0.3s |
| `<工单>/04_voice/<名>_vi_voice.wav` | 无损，供下游合成 |
| `<工单>/04_voice/report.json` | `{voice, gender, segments, placed, failed_ids, avg_tempo, max_tempo, cutoff_ids[], duration, target_duration}` |
| `<工单>/04_voice/qc.md` | 语速分布、被裁句清单、听感自评 |

## 音色（必须与第 2 步判定性别一致）

- 女：`vi-VN-HoaiMyNeural`
- 男：`vi-VN-NamMinhNeural`

## 对齐策略（按顺序执行）

1. **并行合成**：按句拆任务，`asyncio + Semaphore(8)`，单句失败重试 3 次。
2. 首轮 `rate=+0%` 合成 → 实测每句时长。
3. 超 `slot × 1.12` 的句子，按超出比例提 `rate`（最多 +70%）**重合成**（比重采样自然）。
4. 仍超 `slot × 1.02`，用 `atempo` 加速，上限 **1.45x**（再高明显失真）。
5. 硬裁到 `slot`（宁可极轻微截尾，也不要压到下一句头上）。
6. 每句**锚定在原句 `start`**，短了留空档，不累积漂移。
7. 整轨补齐/裁切到源音频时长，首尾各 8ms 淡入淡出防爆音。

## 验收清单（自检通过再交）

- [ ] 总时长与源音频差 ≤ 0.3s
- [ ] 抽 3 处（开头/中段/结尾）听：人声出现在原句位置，偏差 ≤ 0.15s
- [ ] 无相邻两句叠加（听不到两层人声）
- [ ] `avg_tempo ≤ 1.15` 且 `max_tempo ≤ 1.45`；超过 1.3 的句子 ≤ 总数 5%
- [ ] 音色性别 = 第 2 步判定性别
- [ ] 越南语发音正确：抽 10 句检查数字读法、生僻词没有被念成字母（如 "SPF" 类缩写要确认读法）
- [ ] 无爆音、无咔哒声、峰值 ≤ -0.5dBFS

## 打回条件

- `failed_ids` 非空且未补救 → 自己重试。
- `max_tempo` 撞上限仍超时 → 附具体句 id + 实测秒数 + 期望秒数，退回第 3 步压缩。
- 音色性别不对 → 自己修正，这是你的低级错误。
