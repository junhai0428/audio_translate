# 第 3 步 · 翻译控长

## 干什么

上游给的是机器识别出来的、带错别字的口语流水账。你负责：① 校成通顺中文；② 译成越南语，**并且必须短到能塞进原时间轴**。你翻长了，第 4 步就得硬拉语速，成片就废了——长度是你的第一责任，不是第 4 步的。

## 在链路中的位置

```
源音频 → 第 1 步 人声分离 → 第 2 步 语音转写 → 【第 3 步 翻译控长】 → 第 4 步 配音对齐 → 越南语配音轨
```

## 工单输入

- `<工单>/02_asr/asr.json`（第 2 步产物）

## 你必须产出

| 文件 | 要求 |
|---|---|
| `<工单>/03_translate/zh_opt.txt` | `[mm:ss.xx - mm:ss.xx] 校正后的中文`，一行一句 |
| `<工单>/03_translate/vi.txt` | 同格式越南语，行数与中文完全一致 |
| `<工单>/03_translate/segments_vi.json` | `segments:[{id,start,end,slot,max_syl,zh,vi,syl}]`，供第 4 步直接用 |
| `<工单>/03_translate/review.md` | 你改了哪些错别字、哪些句子为控长做了取舍、是否有拿不准的词 |

## 长度预算（硬约束，不许绕过）

```
slot    = min(下一句.start - 0.04, 本句.end + (下一句.start - 本句.end) * 0.85)
max_syl = round((slot - 0.2) * 3.2)        # 3.2 音节/秒（edge-tts +0% 语速实测口径）
```

- 越南语**按空格切音节**，一个词≈一个音节。数字串按 3 位 1 音节估。
- 逐句 `syl <= max_syl`，**全片最好留 10% 余量**（总音节 / 总预算 ≤ 0.95）。
- 超了先压：删重复主语/代词 → 删虚词（thật sự, đúng là, thực ra, nhé, nha, thì, mà）→ 合并同义 → 长定语换短词 → 汉越词换口语词。
- 压不下去的取舍顺序：寒暄 → 重复强调 → 修饰形容词 → 口语插入语。**永不删**：卖点、成分、价格、CTA。

## 翻译质量要求

- 越南口语，像真人在镜头前说话，不要书面语、不要机翻腔。
- 一个空格一个音节，不要堆砌汉越词（`quảng cáo sai sự thật` 这类长短语换短的）。
- 数字用阿拉伯数字；品牌名/型号/单位保留原样。
- 单条最多两个逗号，不加引号、不加 emoji、不加字幕符号。

## 合规（越南广告法，硬红线）

| 中文 | 禁止直译 | 改用 |
|---|---|---|
| 祛湿 / 湿气重 | trừ thấp / loại bỏ thấp khí | `thanh lọc cơ thể`、`giảm cảm giác nặng nề` |
| 健脾 / 养胃 | bổ tỳ / dưỡng vị | `hỗ trợ tiêu hóa` |
| 消肿 | tiêu sưng | `giảm phù nề`（避免疗效承诺） |
| 排毒 | thải độc | `thanh lọc` |
| 治疗 / 根治 / 药效 | điều trị / chữa khỏi | 删除或改 `hỗ trợ` |

不得出现疾病名 + 疗效承诺的组合。

## 验收清单（自检通过再交）

- [ ] `zh_opt.txt` 与 `vi.txt` 行数一致，id 与时间码 1:1
- [ ] 全部 `syl <= max_syl`，总占用 ≤ 0.95
- [ ] 越南语里没有中文字符、没有日韩文、没有 emoji
- [ ] 抽 5 句回译检查：核心信息（数字、卖点、CTA）没丢
- [ ] 合规词逐条过表，`review.md` 里写明改写了哪些
- [ ] 同一术语全片统一（如"香皂"统一 `xà phòng`，不要混 `bánh xà phòng`）

## 打回条件

第 4 步反馈某句念完超出时隙 20% 以上，你必须重压该句并回写 `segments_vi.json`，不许让第 4 步提高语速硬顶。
