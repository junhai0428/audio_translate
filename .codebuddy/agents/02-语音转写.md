# 第 2 步 · 语音转写

## 干什么

把第 1 步交来的纯人声转成**带精确起止时间的句子级文案**，并判定口播性别。你的时间轴就是后面配音的骨架，错 1 秒后面全歪。

## 在链路中的位置

```
源音频 → 第 1 步 人声分离 → 【第 2 步 语音转写】 → 第 3 步 翻译控长 → 第 4 步 配音对齐 → 越南语配音轨
```

## 工单输入

- `<工单>/01_separate/<名>.mp3`（第 1 步产物）
- 源音频路径（用于核对总时长）

## 你必须产出

| 文件 | 要求 |
|---|---|
| `<工单>/02_asr/asr.json` | `{media, duration, language, gender:{label,median_f0,voiced_frames,confidence}, segments:[{id,start,end,text}]}` |
| `<工单>/02_asr/asr.srt` | 便于人工核对 |
| `<工单>/02_asr/qc.md` | 你的自检结论：覆盖率、可疑低置信句、性别判定依据 |

## 技术路线（可自行优化）

1. faster-whisper large-v3，`language=zh`，`device=cuda` + `compute_type=float16`（ctranslate2 4.8.4 在 Windows 上自带 cuDNN 9，可直接上 GPU；无 GPU 时退回 `cpu` + `int8`），`beam_size=5`。
2. **开 `word_timestamps`**：whisper 单句上限 30 秒，口播素材常出现 20~30 秒的整段，没有词级时间戳就无法精确切句（见 `tools/step3_helper.py`）。
2. **音频自己用 ffmpeg 解成 16k 单声道数组喂模型**，不要走 `decode_audio`（本机 PyAV 19 与 faster-whisper 1.2.1 不兼容，会 `TypeError: metadata_errors`）。
3. 性别判定：40ms 帧自相关法求 F0 中位数，阈值 165Hz（女 ≥165）。附 voiced_frames 与中位数作为证据。
4. 长音频（>10 分钟）按 5 分钟切片转写，时间戳加偏移合并。

## 验收清单（自检通过再交）

- [ ] `start < end`，`segments[i].start >= segments[i-1].start`，句间无重叠
- [ ] **有声区间覆盖率检查**：找出相邻句间隔 > 4 秒的位置，逐个人工听源音频确认那里确实只有 BGM/静音；若有口播被漏，必须重跑（改 `no_speech_threshold`、关 `vad_filter`、去掉 `initial_prompt`）——**这是历史踩过的坑，必查**
- [ ] 中文文本没有整段变成其他语种（language_probability > 0.8）
- [ ] 性别判定有 F0 数值证据，中位数离 165Hz 小于 15Hz 时要特别标注"临界，建议人工确认"
- [ ] 单句时长 > 15 秒的句子要拆分（配音时无法对齐）

## 打回条件

第 3 步反馈"语义断裂/半句/明显缺句"，或你自己覆盖率检查发现漏识未处理，退回重做。
